# 中国石油大学（北京）水码自动获取脚本

从中国石油大学（北京）校园卡系统 `vcard.cup.edu.cn` 自动获取饮水机「用水码」的小工具。通过操作学校网页完成登录和取码，登录状态保存在本地浏览器配置目录中，登录过期时用本机加密保存的账号密码自动重新登录。

适用于 Windows 10/11、Python 3.10+，以及 Chrome 或 Microsoft Edge。脚本只操作学校网页，不直接调用未公开接口。首次运行会在此目录创建 `.venv` 和浏览器专用的 `profile-chrome` / `profile-edge`。第一次需要登录时输入账号密码；登录成功后，程序会用 Windows DPAPI 加密保存到 `credentials.dat`。以后登录状态过期时自动读取并提交，无需再次输入。

## 使用

1. 双击 `start.bat`。首次运行会安装 Selenium 和匹配的浏览器驱动，需要联网。
2. 如跳转到学校统一身份认证，在弹出的账号密码窗口中输入学号和密码。脚本会自动登录并从校园卡首页进入“用水码”；成功后保存加密登录信息。如果出现验证码，请在浏览器中完成。
3. 命令窗口显示 `用水码：1234 5678`。以后再次运行通常可复用浏览器配置目录中的登录状态。默认先试 Chrome，再试 Edge。

已有码且页面未标为过期时，默认读取当前码，避免旧码意外失效。要重新生成，在命令提示符中运行 `start.bat --refresh`。只想先登录，运行 `start.bat --login-only`。可用 `--browser chrome` 或 `--browser edge` 固定浏览器。

已有登录状态、想现在保存账号密码时，双击 `save-login.bat`，输入一次即可。学校密码更改后，重新运行 `save-login.bat` 更新。运行 `start.bat --forget-credentials` 可删除本机保存的账号密码。`start.bat --username 学号` 可在首次输入时预填账号。

`credentials.dat` 由当前 Windows 用户加密，换电脑或换 Windows 账号后需要重新输入。`profile-chrome` 和 `profile-edge` 包含登录会话；这些文件和目录都不要发给别人。

如果受限环境中的浏览器无法启动，可双击 `start-compatible.bat`。兼容模式会关闭浏览器沙箱，平常无需使用。本机实际登录和取码验证使用了此模式。

压缩包只包含程序文件，不包含账号密码或浏览器登录状态。

如果页面改版导致找不到按钮，脚本会报错停止，不会猜测水码。此时请对照实际页面调整文字定位。
